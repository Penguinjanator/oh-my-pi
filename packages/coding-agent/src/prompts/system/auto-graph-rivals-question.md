The state is a Markdown table from a coding assistant's answer, with each column's inferred type. A chart will be drawn under the table, marking the best value of each comparison. What competes in this table? Rows when the rows are alternatives scored on the same measures (models, configurations, benchmark arms, plans, tools), so the best row of each column is worth marking. Columns when the numeric columns are alternatives measured on every row (implementations, settings, versions or harnesses side by side for each workload), so the best column of each row is worth marking. Neither when the rows are parts of a whole, steps of a process, files, categories, a before/after pair, or items described side by side rather than ranked.
